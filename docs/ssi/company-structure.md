# AYORAI SSI — Organization Model

The project is structured like a security company with independent control functions.

## Divisions

### SSI Research
Threat research, new attack classes and formal security properties.

### AI Shield
Input, context and output defense.

### RAG Security
Corpus integrity, provenance and retrieval isolation.

### MCP Security
Tool identity, schemas, permissions and egress.

### Agent Defense Lab
Red-team, blue-team, benchmark and regression.

### AI Antivirus
Runtime detection, anomaly scoring and containment.

### Safety Governance
Policy, approval workflows and risk classification.

### Secure Operations
Controlled agent workflows and enterprise automation.

### Audit & Evidence
Traceability, evidence integrity and incident reconstruction.

### Platform Engineering
SDK, gateway, policy engine, APIs and deployment.

### SOC / Incident Response
Detection, triage, containment and recovery.

### Assurance
Threat modeling, independent review, release gates and security claims.

## Independence principle

The team that builds a control should not be the only team that declares the control effective.
