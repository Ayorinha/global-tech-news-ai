# Security Policy

## Scope

This repository contains a public AI-security research laboratory and a separate research track for the future AYORAI AI Shield global cybersecurity platform.

The current browser laboratory is a controlled research system. It is not represented as a universal antivirus, EDR, XDR or mobile-security product.

## Reporting a vulnerability

Please report suspected vulnerabilities through a private GitHub Security Advisory when that feature is available for the repository. Do not publish sensitive exploit details in a public issue.

A report should include:

- affected component or path;
- reproducible description;
- impact;
- version or commit;
- safe reproduction steps;
- suggested mitigation, if known.

Do not include credentials, personal data, malware samples or unauthorized target information.

## Response principles

Reports are triaged according to reproducibility, impact and affected surface. Fixes should include regression coverage where practical.

Security claims will remain scoped to the tested version, platform, configuration and methodology.

## Responsible disclosure

Do not use the project to access, disrupt or test systems without authorization. The research corpus and benchmark must remain controlled and synthetic.
