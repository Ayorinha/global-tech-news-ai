# AYORAI AI Shield — GitHub Engineering Playbook

This project is designed to demonstrate real engineering practice rather than artificial activity.

## Workflow

**Issue → Branch → Commit → Pull Request → Automated Checks → Human Review → Merge → Release/Evidence**

## Skills demonstrated by the repository

- Git branching and commit hygiene
- Pull request design and review
- GitHub Actions CI/CD
- Automated regression validation
- Security documentation
- Threat modeling
- Responsible disclosure
- Dependency update automation
- Reproducible evidence
- Failure-first engineering
- Security claims governance

## Contribution integrity

Activity must correspond to genuine engineering work. Do not manufacture stars, reviews, comments, issues, pull requests or other events solely to obtain badges or achievements.

## Achievements and certifications

GitHub achievements are awarded according to GitHub's own qualifying events and can change over time. This repository can strengthen the evidence of engineering practice, but it cannot guarantee a particular achievement or certification.

Formal certifications, when applicable, require the official GitHub program, eligibility and assessment process.

## Portfolio evidence

The strongest public evidence is:

1. a working project;
2. meaningful commits;
3. reviewable pull requests;
4. passing automated checks;
5. documented security boundaries;
6. reproducible tests;
7. transparent limitations;
8. real external contributions where appropriate.

The deployed site remains separate from the global-platform research branch.
